## 4. 构建方式

需要 FDBus 5.4.0 源码。默认路径为包内 `fdbus-v5.4.0/fdbus-v5.4.0`，也可配置：

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DFDBUS_SOURCE_DIR=/path/to/fdbus-v5.4.0/fdbus-v5.4.0
cmake --build build --target ipc_log_system --parallel
```
