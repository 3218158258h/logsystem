## 4. 构建与运行

包内 `README.md` 给出完整命令。最短路径：

```bash
bash scripts/build.sh
bash scripts/run_server.sh          # 终端 1
bash scripts/run_demo.sh demo-a     # 终端 2
bash scripts/run_demo.sh demo-b     # 终端 3
```

FDBus 源码默认查找包内 `fdbus-v5.4.0/fdbus-v5.4.0`，也可通过 `-DFDBUS_SOURCE_DIR=...` 指向外部目录。

Windows 下双击 `Windows提交命令.bat` 可定位 Git 仓库根目录，按白名单暂存并生成符合题目格式的提交；脚本不自动 push。
